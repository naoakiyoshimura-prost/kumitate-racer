# ランク・コスト・通貨 仕様メモ（v0.1 / 2026-10-09）

よっし店長の方針：パーツの種類を増やし、ランクとコストで縛る。クリアしながらパーツを集める。
「今どきのレーシングソシャゲくらいのセッティング幅」で、すぐコンプリートして飽きないようにする。

## 1. ランク（モーターを軸に5段階）
| ランク | 記号 | 目安 |
|---|---|---|
| ノーマル | N | 最初から持っている |
| チューンド | T | 序盤のレースで買える |
| ハイパー | H | 中盤 |
| レーシング | R | 終盤 |
| EX | EX | 最上位。高額 |

- モーターは全ランクにある。他のパーツもランクごとに性能差を付ける
- 上のランクほど「強いが重い・高コスト・扱いが難しい」。プラスしかないパーツは作らない

## 2. コスト（ランクポイント）
- 全パーツに **コスト** を付ける。マシンの合計コストが、レースの **コスト上限** 以下でないと出られない
- レースごとに **単品コスト上限** もある（例：単品4までのレースでは、ハイパーモーター（7）は使えない）
- 強いパーツほどコストが高いので、「どこにコストを使うか」がセッティングの悩みどころになる
  - 例：高速ギヤ（3.55:1）はコスト3。一択化していたので、コストで縛る

## 3. レース（大会）とクリア
- `src/data/events.json` に定義。コース、周回、コスト上限、単品上限、CPUのセッティング、賞金（1位/2位）
- 1位で次のレースが解放される。クリア済みのレースも、何度でも賞金を稼げる
- フリー走行：好きなコース・所持パーツ自由。賞金なし（稼ぎ放題を防ぐ）

## 4. 通貨とショップ
- 通貨：**G（ガレージコイン）**。レースの賞金でのみ増える
- ガレージで未所持パーツをタップすると価格が出て、購入ボタンで買える
- 所持金・所持パーツ・クリア状況は端末（ブラウザ）に保存

## 5. 辛口メモ（リスクとヘッジ）
| リスク | 根拠 | ヘッジ |
|---|---|---|
| **課金を入れると法規制の対象** | 有償の通貨は資金決済法（前払式支払手段）、ガチャの「コンプガチャ」は景品表示法で禁止。確率表示の自主規制もある | 当面、通貨はレースでのみ稼げる無償通貨にする。課金を入れるなら必ず専門家に確認 |
| **端末保存はすぐ改ざん・消失する** | ブラウザ保存は利用者が自由に書き換え・削除できる | ランキングやピットボード連携を始める段階で、サーバー側に保存を移す。それまでは「遊びのデータ」と割り切る |
| **経済のバランス崩壊** | ソシャゲの不満の大半は「稼げない／インフレ」 | 賞金と価格は events.json と parts.json に集約。1つのレースを何周すれば次のパーツが買えるかを表で管理する |
| **パーツを増やすほど一択化** | 既に3.55:1ギヤと高回転型が上位独占しかけた | 追加のたびに npm run searchbuild を回す。コスト上限ごとの上位も確認する |

## 追記: インフレ・デフレ（2026-10-09 店長案）
- 大会にクラス（N/T/H/R/EX）を付けた。自分のクラス＝いま挑戦できる一番上の大会のクラス。
- 自分より下のクラスの大会は賞金が減る: 1クラス下×0.5、2クラス下×0.25（最低×0.1）。
- 上位ランクのパーツ価格は約3倍に引き上げ（ハイパーモーター4500G、レーシング12000G、EX 39600G）。賞金も上のクラスほど増える（チューンドGP 2000G → EXグランプリ 40000G）。
- 目安: 次のランクのパーツは「適正クラスの大会で2〜4勝」、格下大会で稼ぐとその2〜4倍の回数が必要。

## 追記: 改造段階と部品の細分化（2026-10-09 店長案）
- 所持パーツは+1〜+3まで改造できる。コストは変わらず性能だけ上がる（効き方は parts.json の upgrade）。改造費は価格×0.3/0.6/1.0（最低300G基準）。
- 大会CPUも改造段階を持つ（events.json の cpuLevel）。
- ローラー・バンパー・ウィング・マスダンパーは前後別。前は衝撃（コースアウト耐性）、後ろは壁沿いの減速に効く。ウィングは前後両方付けると空力バランスでダウンフォース×1.2。
- 追加: 軸受け（ベアリング/強化ベアリング＝加速）、サスペンション（安定感↑・重量↑）、軽量化キット1〜3（加速・最高速↑、安定感↓、高級品）、バンパー（FRP/カーボン/ハードカーボン）。
- 変形できるのはシフトランナー、ストームシフターだけ（変形機構のぶん重い）。
