# セッティング仕様メモ（v0.1 / 2026-10-09 よっし店長の案）

段階⑧「カスタマイズ」で実装する。ミニ四駆・ラジコンの実車の概念をベースにする。

## 店長の案
| パーツ | 性能の考え方 |
|---|---|
| タイヤ（グリップ） | ハイグリップ＝コーナー追従性が高いが、モーターが弱いと抵抗で減速。ローグリップ＝流されやすいが減速しにくい |
| タイヤ寿命 | ハイグリップはコーナー負荷をかけすぎると摩耗してグリップが落ちていく |
| タイヤ径 | 大径＝最高速↑加速↓、小径＝加速↑最高速↓（ギヤ比と同じ方向の効果） |
| トレッド幅 | 広い＝グリップ↑・抵抗↑ |
| ローラー | 前後4か所をベース。配置と径で壁沿いの減速量・コースアウト耐性が変わる |
| モーター | 加速（トルク）と最高速（回転数）の2軸 |
| モーター搭載位置 | 前/中/後で重心が変わり、コーナー挙動に差（例：後ろ寄り＝流れやすいが立ち上がり加速◎） |
| ギヤ比 | 加速寄り⇔最高速寄り |
| アップダウン | コースに高低差。登りで減速、下りで加速、頂上で浮く（ジャンプ段階と統合） |

## 実装の型（今のコードとつなげる方法）
- パーツは JSON（parts.json）で定義し、組み合わせから「走行性能値」を計算する関数を1つ作る。
  - 例：maxSpeed = モーター回転数 × タイヤ径 ÷ ギヤ比 × 抵抗係数
  - accel = モータートルク × ギヤ比 ÷ タイヤ径 ÷ 車重
  - grip = タイヤグリップ × トレッド幅係数 × 摩耗率
- 走行計算（car.ts）は今と同じ「maxSpeed / accel / grip / ローラー係数」だけを見る。パーツが増えても走行計算は変えない。
- タイヤ摩耗：コーナーで pull（遠心力の超過分）が大きいほど摩耗が進み、grip に掛かる摩耗率が下がる。

## 辛口メモ（リスク）
- **パラメータが増えるほど「最適解が1つ」になりやすい。** 全項目にトレードオフ（得るものと失うもの）を必ず付ける。プラスしかないパーツは作らない。
- **数字を全部見せると、スマホでは読まれない。** 画面ではレーダーチャート（最高速・加速・コーナー・耐久・安定）にまとめて見せる。
- **バランス調整は人間の仕事。** 計算式と数値は JSON に出し、npm run sim で比較してから決める。AIに「いい感じに」を繰り返し頼まない。
- アップダウンは見えないレールに高さを足すだけなので技術的には軽い。ただしジャンプ（浮く）と組み合わせるとバグが増えるので、⑦ジャンプ段階で一緒にやる。

## 追加（2026-10-09 よっし店長）
- ジャンプの着地NGゾーンは廃止。大ジャンプを楽しめるようにする
- 「着地安定性」ステータス：着地の衝撃が上回ると乱れ、大きく上回るほどコースアウト確率が上がる（コーナーと同じ考え方）。大径・高速ほど衝撃が大きい
- 標準セッティングは着地安定性が少し足りず、ジャンプで乱れる
- ウィング（ダウンフォース：速いほどグリップ↑、着地安定↑、空気抵抗・重さ↑）、マスダンパー（着地安定↑、重さ↑）
- 加速型はジャンプで攻められる（速度が低めなので着地が安定）
- コースを複数用意する
