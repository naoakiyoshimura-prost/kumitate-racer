# マシンのデザイン方針（2026-11-11 第1弾: 日本6メーカー×1台）

店長の指示（2026-11-11）: 箱だけのマシンをかっこよく。メーカー別に1〜2台ずつ、各車に「ボディテーマとコンセプト」を決めてから作る。エアロモードの可動（ウィングの動き、ブースターの設置余地、カウルを大きく動かす）を前提にする。

参考にしたもの: 店長のドライブにある自作のデザイン画（12メーカー・26台の4面図）。画像そのものはリポジトリに入れず、形の方向だけを参考にしてコードで作る。玩具アニメ・近未来フォーミュラ・海外スーパーカーは「雰囲気の方向」としてだけ参考にし、特定の車種・マシンの形や名前、ロゴは写さない。

共通の決まり
- 板を1枚押し出した箱をやめ、「ノーズ・左右のフェンダー・キャビン・背骨・後端」を別の面で組む。面の折れ目で光が切り替わるようにする（質感より形が先）。
- 色は車体色（選んだ色）＋黒い骨格＋差し色1つ。差し色はメーカーごとに決める。
- エアロモードは車ごとに動く場所を変える。共通化を強制しない。
- ブースターの置き場所（後端・背中・左右）を形の段階で空けておく。
- スマホで30fpsを保つ。1台の三角形は今の数倍までに抑え、材質はできるだけ共有する。

## 第2弾: 海外6メーカー×1台（2026-11-11、見た目だけ）

参考にしたもの: 店長のドライブにある海外6メーカーの4面図（オリジナル設定画）。画像はリポジトリに入れず、形の方向だけをコードで作る。実在の車・模型・作品の形や名前、ロゴは写さない。

扱い: **見た目だけのデザイン見本**。parts.json にボディを足していないので、値段・性能・セーブ・シミュは変わらない。URL の `?look=<id>`（vector / crimson / pearl / clover / ivory / regent）か、ガレージの「🎨 見本」で選ぶと、自分の車の3Dの形だけが差し替わる（レース中・俯瞰モードも）。選んだ見本は URL に書き戻すだけでセーブしない。ガレージの「エアロを開く/閉じる」で、変形シャーシでなくても可動を確かめられる（既製6ボディにも効く）。

日本6台より一段作り込む決まり
- 面の折れ・段差・吸気口・フィン・ランプを足して、正面と後ろに「顔」を持たせる（前照灯の材質を1つ追加）。横から見て薄くならないよう、肩の線をタイヤの上端より上に置く。
- 1台の三角形は 4輪で約1,000〜1,650（6輪・8輪で最大約1,950）、メッシュは11〜15。貼る板（線・通気口・ランプ）は縁の面取りをしない、フルカウルのアーチは刻みを少し粗くする、で抑えた。
- ブースターの空き: 後端の中央（|x|<0.36、z<-0.76）は従来どおり空ける。2連ポッドの腕（後輪の少し前を左右に渡る）と4連ポッドのレール（背中の後ろ）に当たらないよう、背中の後ろの高さ・翼の動きをブースターの種類で変える。
